# Homepage News Fallback Image

**Purpose**: Default image for a news item that has no thumbnail of its own.

**Recommended ratio**: 4:3
**Recommended size**: 1600×1200 (minimum 1200×900)

**Files**:
- `home-news-default.jpg`

Note: the current homepage "最新消息" section is a text-only teaser list (matching the official
site's homepage layout) — this file is reserved for a future redesign that adds thumbnails, and is
not currently rendered on the page.
