# Homepage Solutions Card Images

**Purpose**: One image per solution card in "四大領域解決方案".

**Recommended ratio**: 4:3
**Recommended size**: 1600×1200 (minimum 1200×900)

**Files** (mapped in `src/data/homepage-media.ts` → `solutions`):
- `home-solution-police.jpg` — 警勤模擬訓練 (law-enforcement)
- `home-solution-military.jpg` — 軍事模擬訓練 (defense)
- `home-solution-smart-city.jpg` — 智慧城市應用
- `home-solution-fire.jpg` — 消防防救災訓練

Do not add new files here to introduce a 5th solution — the homepage list is driven by
`src/content/solutions/*.zh-tw.md`; adding an image alone will not create a new card.
