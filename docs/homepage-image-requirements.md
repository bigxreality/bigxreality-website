## 逐項詳細規格

### home-hero-main（Hero 主視覺）
1. **圖片內容描述**：受訓者（軍警或消防人員）實際使用 Big x Reality XR 訓練系統的畫面，需可見頭戴裝置／控制器等硬體與虛擬訓練環境的疊加效果。
2. **構圖需求**：主體人物置於畫面中至右側，左側 40% 保留給 Hero 文字區（H1、副標、CTA），避免臉部或裝備被文字遮擋。
3. **素材種類**：實拍照片，後製加入 XR overlay。
4. **電腦版與手機版**：桌機 16:9（2560×1440）／手機 4:5（1440×1800，直式重新構圖，非單純裁切放大）；兩版不可共用同一構圖，需個別拍攝或重新構圖。
5. **後製需求**：加入 spatial grid／tracking node／target marker 等克制的 XR 疊加層；統一色調（偏深藍與品牌紅）；隱藏可辨識之機敏裝備型號；如涉及真人需確認肖像授權。
6. **優先級**：P0（沒有就無法完成首頁）。

### home-about-main（公司簡介主圖）
1. **內容**：能代表公司核心系統整合能力的畫面，例如控制室、教官操作介面或多螢幕資料儀表板。
2. **構圖**：置中或置右皆可，需在 4:3 比例下保留四周留白。
3. **素材種類**：實拍照片或系統介面截圖。
4. **電腦版／手機版**：可共用同一張（正方形/4:3 裁切皆可讀）。
5. **後製**：統一色調、必要時模糊或去除畫面中的機敏資訊。
6. **優先級**：P1。

### solution-law-enforcement／solution-defense／solution-smart-city／solution-fire-rescue
1. **內容**：對應各解決方案分類的實景訓練畫面 — 警勤盤查演練／軍事戰術兵推／智慧城市指揮中心／消防搶救演練。
2. **構圖**：人物或系統主體置中，四邊留白供卡片文字與 hover XR 標籤使用；避免關鍵資訊落在卡片四角（會被圓角裁切）。
3. **素材種類**：實拍照片為主；smart-city 可用系統介面截圖或合成視覺。
4. **電腦版／手機版**：可共用同一張 4:3 素材（卡片版位不做手機獨立裁切）。
5. **後製**：加入輕量 XR overlay（如節點標記）以呼應 hover 效果；統一色調；隱藏無授權揭露的臉部或單位識別。
6. **優先級**：law-enforcement 與 fire-rescue 為 P0（首頁最主要呈現的兩類服務對象）；defense 與 smart-city 為 P1。

### package-01 / package-02 / package-03（套裝方案主視覺）
1. **狀態**：**文案與圖片皆待確認** — 定案設計稿未提供首頁套裝方案的產品名稱與敘述，因此圖片需求暫以「產品去背圖」規格佔位，實際主體待官方提供產品清單後才能確認。
2. **構圖需求**：乾淨背景、去背主體置中，四周需留白供 PT Mono 型號標籤與底部標題文字使用。
3. **素材種類**：產品去背圖（建議白底或透明背景拍攝後去背）。
4. **電腦版／手機版**：可共用同一張。
5. **後製**：去背、統一光源與色調；若涉及 Reality／XR 雙視角效果，需額外提供一張「XR 介面截圖」版本供 hover 切換使用。
6. **優先級**：P1，但需等產品清單確認後才能真正開始拍攝／製作。

### case-airport／case-police／case-fire（精選案例）
1. **內容**：分別對應機場空側駕駛模擬訓練、警察局勤務情境訓練中心、火災搶救指揮模擬系統三個實際案例場域。
2. **構圖**：可用場域全景或使用者操作特寫，主體置中，預留下方色塊供 CASE 編號標籤。
3. **素材種類**：實拍照片，優先使用該案例的實際部署或驗收畫面。
4. **電腦版／手機版**：可共用同一張 4:3 素材。
5. **後製**：統一色調、隱藏客戶端不對外公開的識別資訊、確認客戶是否同意此案例公開露出於官網首頁。
6. **優先級**：P1。

### news-thumbnails（最新消息縮圖）
1. **內容**：對應 CMS 中最新 3 則消息的縮圖，非首頁獨立拍攝素材。
2. **構圖**：依新聞類型（COMPANY／INSIGHT／INDUSTRY）提供對應代表圖或活動照。
3. **素材種類**：CMS 既有縮圖或活動紀錄照片。
4. **電腦版／手機版**：可共用；主新聞（桌機左側大圖）建議額外提供 16:9 裁切。
5. **後製**：僅需基本色調統一，不需 XR overlay。
6. **優先級**：P2（可先用現有 CMS 素材或延後上線）。

### trusted-by-logos（合作與服務單位標誌）
1. **內容**：內政部警政署／國防部／國家發展委員會／各縣市消防局／智慧城市推動辦公室之標誌或名稱。
2. **構圖**：單色或原色標誌皆可，統一高度置中排列。
3. **素材種類**：官方標誌（向量圖優先）。
4. **電腦版／手機版**：可共用，手機版改為可橫向捲動或換行排列。
5. **後製**：需確認每個政府單位標誌的使用是否需要正式授權／行文同意；目前首頁僅以純文字呈現單位名稱，尚未使用任何標誌圖檔。
6. **優先級**：P2（目前以文字替代，標誌屬加分項目，上線前需完成授權確認）。

## 圖片元件實作說明

所有首頁圖片皆透過 `lib/data/homepage-media.ts` 的 `homepageMedia` 表管理，每筆資料包含
`desktop`／`mobile` 路徑、`alt`、桌機與手機的 `width`／`height`（用於避免 layout shift）。
`components/ui/PlaceholderImage.tsx` 目前依此資料渲染尺寸正確的佔位視覺框；正式素材到位後，
只需將對應元件內的 `<PlaceholderImage asset={...} />` 換成 `<Image src={asset.desktop} ... />`
（搭配 `sizes`、`priority`（僅 Hero）、非首屏預設 `loading="lazy"`），資料結構不需變動。
